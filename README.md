# 2026_257Tecan
Repository for Tecan testing, demos, and deck-validation workflows associated with the restart of the 257 Tecan in 2026.

## Overview
This repository is intended to hold scripts, test jobs, and example workflows used to validate automation and liquid-handling behavior on the Tecan system. The work here is focused on practical lab-automation setup, deck positioning, shared-tip handling, and demonstration protocols that can be expanded into later chemistry workflows.

## Contents
The repository includes:
- a set of PyLabRobot demo scripts
- simple deck layout and position-check examples
- template workflows for liquid transfer and source/destination testing
- a toy SPPS-style demonstration job used for early protocol development

## Primary use
The code in this repo is meant to support:
- confirming deck geometry and movement on the robot
- testing aspiration/dispense logic and shared-tip behavior
- building reusable automation workflows before moving to more complex chemistry tasks
- documenting the 2026 restart and validation work for the 257 Tecan system
